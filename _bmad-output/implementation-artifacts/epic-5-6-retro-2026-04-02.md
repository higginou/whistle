## Insights Cles

1. **Les gates mecaniques sont la seule methode d'enforcement qui marche** — 3 retros a identifier le probleme fichier story, resolu en une gate. Les regles dans le DoD ne suffisent pas. Il faut bloquer les transitions dans le workflow.
2. **Le code review catche des bugs critiques quand il est fait** — le bug simulateur (points rugby discards) aurait corrompu toutes les projections. Mais il n'est fait que sur 2/6 stories. Le ROI d'un review systematique est enorme.
3. **Les Dev Notes detaillees correlent avec la qualite** — les stories avec les meilleures notes techniques (6-1, 6-2) sont aussi celles avec les meilleures reviews et zero debug.
4. **Le pattern "pre-existant donc pas mon probleme" est une dette qui s'accumule** — 19 tests en Epic 1, corriges en Epic 5. 3 tests en Epic 6, a corriger maintenant.

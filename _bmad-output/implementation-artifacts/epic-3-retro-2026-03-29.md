## Defis

1. **Stories fantomes (3-1, 3-5)** — done dans sprint-status mais pas de fichier story dans implementation-artifacts. Pas de dev notes, pas de review, pas de tracabilite. Consequence directe de l'action item non tenu (template Dev Agent Record).
2. **Accessibilite angle mort systematique** — findings a11y dans 100% des stories reviewees (3/3) : aria-label oublie (3-2), tabindex manquant (3-3), keyboard support (3-4).
3. **Securite innerHTML** — XSS via `team.name` non echappe dans story 3-3. Corrige avec helper `esc()`, mais le reflexe d'echappement n'est pas automatique.
4. **Cleanup store incomplet** — `selectedTeam` jamais remis a null dans story 3-4 (Changes Requested, corrige cycle 2).
5. **Duplication code** — `TEAM_COLORS` et `getInitials` dupliques entre `rank-row.js` et `bottom-sheet.js`.

## Insights Cles

1. **Les spikes pre-epic sont un multiplicateur de vitesse** — a repeter systematiquement pour chaque epic avec une composante technique inconnue.
2. **Le gate maquettes elimine le retravail UI** — processus mature, ne pas toucher.
3. **Les engagements process non tenus ont des consequences mesurables** — le template Dev Agent Record doit etre rendu obligatoire, pas optionnel.
4. **L'accessibilite a besoin d'une checklist integree** — la bonne volonte ne suffit pas, il faut un mecanisme de rappel au bon moment (dans la story).

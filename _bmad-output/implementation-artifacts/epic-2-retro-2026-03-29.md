## Pattern Slot Persistant (reference Epic 3)

**Probleme :** `innerHTML` detruit les noeuds DOM enfants et invalide les closures qui les referencent. Un composant enfant avec son propre cycle de vie (listeners store) perd sa reference container.

**Solution (decouverte story 2-5) :**
1. Creer l'element slot **une seule fois** via `document.createElement()`, en dehors du cycle `buildHTML()`
2. Apres chaque `innerHTML`, **re-attacher** le slot dans le DOM parent : `parent.appendChild(slot)`
3. Le composant enfant recoit le slot une seule fois via `render(slot)` — la reference reste valide car le noeud n'est jamais detruit, seulement detache/re-attache

**Exemple :** `score-card.js` lignes 236-250 — `badgeSlot` cree une fois, re-attache dans le header apres chaque `article.innerHTML = buildHTML(...)`.

**Appliquer dans l'Epic 3 pour :** lignes d'equipe animees (story 3-1/3-2), bottom sheet (story 3-4) — tout composant enfant qui ecoute le store et doit survivre a un re-render parent.

## Preparation Epic 3 : Classement Anime & Exploration des Equipes

### Taches Preparation (toutes done)

#### Spike Motion v12 ✅
- Import : `animate` depuis `motion/mini` (~2.5KB gz) + `spring` depuis `motion` (~0.5KB gz)
- Total : ~3-3.5 KB gzipped — dans le budget
- API spring : `{ type: spring, stiffness: 200, damping: 20 }` (passer l'objet, pas un string)
- Stagger : `stagger(0.03)` ou fonction custom pour La Rochelle +100ms
- Orchestration : `await animate(...).finished`
- Reduced motion : detection manuelle via `matchMedia`, pas automatique
- Gotcha : animer element par element pour la graduation (pas en groupe)
- Gotcha : `will-change: transform, opacity` en CSS sur elements animes

#### Spike Bottom Sheet ✅
- Approche : `<dialog>` natif avec `showModal()` — focus trap, aria-modal, backdrop gratuits
- Slide : CSS `transform: translateY()` + transition 300ms ease-out
- Drag : touch events sur le handle uniquement, `{ passive: false }` pour touchmove
- Snap : 3 positions (ferme 100dvh, mi-hauteur 50dvh, plein ecran 0)
- Backdrop : `@keyframes` (pas `transition`) pour compatibilite
- Popstate : animer → `dialog.close()` → `history.back()`, guard double-close
- Gotcha : `dialog.close()` retire du top layer instantanement — toujours animer avant
- Gotcha : `transitionend` peut ne pas fire — fallback `setTimeout`
- Gotcha : utiliser `dvh` au lieu de `vh`

#### Strategie Test Animations ✅
- **Unit tests** : logique d'animation (quel spring pour N places, stagger order, reduced motion branch), etat store, classes CSS appliquees, snap decision (position + velocity)
- **Mock `animate()`** : verifier les configs passees a Motion (stiffness, damping, delay)
- **Pas d'E2E animations** : validation visuelle manuelle sur device

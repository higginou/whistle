# Retrospective Epic 11 : Retrait du pipeline legacy

Date : 2026-05-04
Status : done

## Epic Review

Epic 11 a retire le scraping, les workflows GitHub Actions et les payloads statiques du chemin de production. Le runtime actif est maintenant Vercel : API publique, API admin, Postgres et recalcul serveur.

## Ce qui a bien fonctionne

- Les tests de garde ont ete inverses proprement : ils verifient maintenant l'absence du pipeline legacy au lieu de sa presence.
- Le front public lit un seul contrat actif via `GET /api/public/season?season=2025-2026`.
- La review automatique a detecte une vraie regression Donjon liee au changement de source des resultats.
- Les scripts historiques restent disponibles sans etre presentes comme runtime actif.

## Points de vigilance

- Le vocabulaire historique `pipeline`, `scraped`, `GitHub Pages` reste present dans des documents anciens. Une note post-migration dans l'architecture clarifie que ces sections sont historiques.
- Les resultats Vercel ne contiennent pas les essais. Donjon doit donc continuer a traiter les essais comme optionnels tant que le schema DB ne les stocke pas.
- Les fichiers `data/` restent utiles comme fixtures/historique local, mais ne doivent pas redevenir une source publique active.

## Corrections post-review

- Donjon normalise les essais absents a `null`.
- Le combat masque les lignes d'essais si elles ne sont pas connues.
- La finale n'affiche plus de total d'essais lorsque les donnees sont incompletes.
- Les tests couvrent le payload Vercel `results` sans `homeTries` / `awayTries`.
